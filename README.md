# pycharm-run-notifier

PyCharm 运行结束提醒计时器：每次 PyCharm 中的 Python 运行结束后，自动倒计时 60 秒，然后播放提示铃声，提醒你「运行已结束」。

## 项目背景

最近在跑图，一个图就得一个多小时，中途还得手动填入新的文件，手动操作。但是如果人一直在旁边盯着可太难受了。所以我就试着用 vibe coding 写了一个可以监测进程的东西，看看效果。
功能很简单，新手第一次尝试(●ˇ∀ˇ●)

## 功能

- 自动检测 PyCharm 中的 Python 运行（Run / Debug / 终端内运行）
- 运行结束后开始倒计时（默认 60 秒，基于系统时钟计时，显示预计响铃时间）
- 倒计时结束播放「叮-叮-叮——咚」提示铃声
- 循环监控，每次运行结束都会提醒

## 使用方法

方式一：双击 `start_timer.bat`

方式二：命令行运行

```
python pycharm_run_timer.py
```

然后正常在 PyCharm 里运行你的代码即可，运行结束后计时器会自动开始倒计时并响铃。计时器窗口保持运行即可（可以最小化）。

## 个性化修改

所有可以修改的地方都在 `pycharm_run_timer.py` 里做了标记（① ② ③ ④），文件开头的「个性化修改指南」有完整说明，例如：

| 标记 | 含义 | 默认值 |
| ---- | ---- | ------ |
| ① | 倒计时秒数 | 60 秒 |
| ② | 检测间隔 | 1 秒 |
| ③ | 铃声重复轮数 | 3 轮 |
| ④ | 铃声音调 | 叮叮叮——咚 |

## 环境要求

- Windows
- Python 3（仅使用标准库，无需安装任何第三方包）
